# Contributing to Chief Wiggum

Thank you for your interest in contributing to Chief Wiggum! 🎖️

## How to Contribute

### Reporting Issues

- Use GitHub Issues to report bugs or request features
- Include clear reproduction steps for bugs
- For feature requests, explain the use case

### Pull Requests

1. **Fork the repository**
2. **Create a feature branch** from `main`
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Make your changes**
4. **Test your changes** in a real project
5. **Submit a PR** with a clear description

### PR Requirements

- [ ] Clear description of changes
- [ ] Documentation updated (if applicable)
- [ ] Works with at least one AI IDE (Cursor, Windsurf, Claude Code, etc.)

## What We're Looking For

### High Priority
- Support for additional AI coding assistants
- Improvements to autonomous loop reliability
- Better error recovery and logging
- Project type detection improvements

### Documentation
- More IDE-specific guides
- Real-world usage examples
- Video tutorials

### Scripts
- Improvements to `init-ralph.js` detection
- Better coverage checking
- Additional helper scripts

## Code Style

- Use clear, descriptive names
- Include comments for complex logic
- Follow existing patterns in the codebase

## Questions?

Open an issue with the `question` label.
